# Pilot Nightingale as an EHR collaboration layer

The next product stage is a single-clinic, clinician-led Pilot focused on consult preparation and staff follow-up. It will use synthetic or de-identified data while validating workflow value; the EHR remains the system of record for formal documentation, orders, and billing. This deliberately avoids treating a successful prototype as permission to process unrestricted PHI or replace an EHR before governance, integrations, and clinical safety have been earned.
